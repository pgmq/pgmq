# Security Policy

## Supported Versions

| Version  | Supported          |
| -------- | ------------------ |
| >= 1.3.2 | :white_check_mark: |
| < 1.3.2  | :x:                |

## Reporting a Vulnerability

Please use GitHub's built-in [private vulnerability reporting](https://github.com/pgmq/pgmq/security/advisories/new) to report any security issues you find in pgmq. Please do not open public issues for security vulnerabilities. We will respond promptly to discuss the path forward. Thank you for helping keep pgmq secure!
